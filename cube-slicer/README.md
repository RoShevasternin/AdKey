# Cube Slicer — пітч і прототип

Концепт мобільної гри: механіка Fruit Ninja в блоковому стилі Roblox, за розрізані фрукти гравець отримує RBX і виводить їх за роадмапом (1 → 5 → 25 → 100 → 500). Замість бомби — рекламна коробка (+0.25 RBX за 5 секунд реклами).

- `src/game.jsx` — увесь код: лендинг (UA/RU/EN) і гра в телефоні (React).
- `src/page.html` — стилі та каркас сторінки.
- `build.sh` — компілює JSX (esbuild) і збирає `cube-slicer.html` (Claude Artifact) та `index.html` (звичайний HTML).

Збірка: `./build.sh` (потрібні Node.js і доступ до npm).

У прототипі виведення RBX і реклама імітуються. Прогрес гравця зберігається в браузері (localStorage).
